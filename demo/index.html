Same rules, different world

Six worlds. One attribute.

A world is a set of tokens: lacquer, metal, paper, key light, type. Put data-wow-world on any element and every surface inside re-skins at once. Click one to make it the page.

Nothing simply fades in

Real springs, exported as CSS.

The kit solves a damped spring exactly and returns a CSS linear() easing with its settle time. It takes the same two numbers as SwiftUI's .spring(response:dampingFraction:), so the web screen and its native twin move the same.

Banknote line work

        
A guilloché generator.

        
Sums of sine rings, offset in phase, like the engraving on a banknote. Deterministic SVG you can export. The kit uses it for the slowly turning rosette, card backs and certificate borders.

      

      

        

          

          

          

          

          

          

        

        

      

    


    
    

      

        
The banned list, enforced

        
A linter that fails flat UI.

        
wow-lint reads CSS, HTML, JSX, Vue, Svelte and SwiftUI and fails the build on the things the standard bans: stock spinners, plain fades, linear easing, flat grey borders, flat yellow "gold", controls that do nothing, icon buttons with no label, and motion with no Reduce Motion fallback.

Use it

        
For you, and for your AI.

        
The standard is written to be pasted at the top of any UI task, for any AI. It also ships as a Claude Code skill.

      

      

        

          
In a page

          
Copy kit/ and one world, or load them from a CDN. No build step.

          
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/mthburnsbarber-web/wow-ui@v1.0.0/kit/wow.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/mthburnsbarber-web/wow-ui@v1.0.0/worlds/worlds.css">

<body class="wow-scene" data-wow-world="card-table">
  <div class="wow-card wow-tilt wow-foil wow-glint" data-wow-tilt>…</div>

<script type="module">
  import * as wow from 'https://cdn.jsdelivr.net/gh/mthburnsbarber-web/wow-ui@v1.0.0/kit/wow.js';
  wow.auto();
</script>

        

        

          
In Claude Code

          
Install it as a skill. Every UI task loads the standard, uses the kit, and runs the linter and the contact sheet before calling it done.

          
git clone https://github.com/mthburnsbarber-web/wow-ui ~/.claude/skills/wow-ui

          
Any other agent: add one line to AGENTS.md.

          
Before any UI work, read and follow STANDARD.md from github.com/mthburnsbarber-web/wow-ui, then run `npx github:mthburnsbarber-web/wow-ui lint` on the changed files.

        

      

      

        
The ten rules

        
    
          
  1. Choose one physical world and make every element a real object in it. Materials, weight and light, not a palette.
    2. 
          
  2. One signature hero object: touchable, tilts with the device, catches light, has weight, appears everywhere.
    3. 
          
  3. Every control is an object from that world. A button is a chip. An error is the Joker.
    4. 
          
  4. Every motion is a verb: deal, flip, toss, stack, shuffle, reveal. Springs and haptics, never a plain fade.
    5. 
          
  5. One material system applied through tokens, so every screen changes at once.
    6. 
          
  6. Use the hardware: gyroscope, haptics, audio-reactive visuals, GPU shaders for the big moments.
    7. 
          
  7. Design every state as an object. No control silently does nothing.
    8. 
          
  8. Ship the craft: device-resolution textures, 60 fps, Reduce Motion, Dynamic Type, labels on everything.
    9. 
          
  9. Be unmistakably yours. No rotating asterisks, pulsing orbs or other AI products' signatures.
    10. 
          
  10. Judge it as one artwork: a contact sheet of every screen, before and after, then a real device by hand.
    11.
